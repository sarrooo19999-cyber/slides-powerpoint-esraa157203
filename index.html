عرض تقديمي تفاعلي

من الفكرة إلى إطلاق موقعك الإلكتروني

رحلة عملية توضح المراحل الأساسية لإنشاء موقع إلكتروني وتجهيزه ونشره على الإنترنت.

إعداد وتصميم: إسراء ناصر

🎯
الخطوة 01

تحديد الهدف من المشروع

قبل البدء في إنشاء الموقع، يجب تحديد فكرته والهدف الأساسي منه، ومعرفة الجمهور المستهدف والخدمات أو المعلومات التي سيقدمها.

تحديد فكرة الموقع
تحديد الجمهور المستهدف
تحديد الصفحات المطلوبة
تحديد شكل الموقع ووظيفته
✍️
الخطوة 02

تجهيز محتوى المشروع (Prompt)

نكتب وصفًا واضحًا ومفصلًا للموقع المطلوب، يتضمن التصميم والألوان والأقسام والوظائف، ثم نستخدمه مع أدوات الذكاء الاصطناعي للمساعدة في بناء الموقع.

مثال على البرومبت:

أنشئ موقعًا إلكترونيًا احترافيًا ومتجاوبًا، بتصميم عصري، مع صفحة رئيسية وأقسام واضحة وألوان متناسقة.

📁
الخطوة 03

إنشاء مستودع المشروع

ننشئ مستودعًا (Repository) على منصة GitHub لحفظ ملفات المشروع وتنظيمها، ومتابعة التعديلات عليها.

الدخول إلى GitHub
اختيار New Repository
كتابة اسم المستودع
الضغط على Create Repository
💻
الخطوة 04

تجهيز ملفات موقع المشروع

نجهز ملفات الموقع وننظمها داخل مجلد المشروع، بحيث يكون لكل ملف وظيفة محددة.

my-website/
├── index.html
├── assets/
│   ├── css/
│   │   └── style.css
│   └── js/
│       └── slides.js
└── images/
☁️
الخطوة 05

رفع ملفات المشروع إلى المستودع

بعد الانتهاء من تجهيز الملفات، نرفعها إلى مستودع GitHub حتى تصبح محفوظة على الإنترنت وجاهزة للربط بمنصة الاستضافة.

فتح المستودع على GitHub
اختيار Add File
اختيار Upload Files
رفع الملفات والضغط على Commit Changes
🔗
الخطوة 06

ربط المستودع بحساب الاستضافة

نربط مستودع GitHub بمنصة استضافة مثل Netlify أو Vercel، حتى تتمكن المنصة من الوصول إلى ملفات المشروع وتجهيزها للنشر.

نختار إضافة مشروع جديد، ثم نربط حساب GitHub، ونحدد المستودع الذي يحتوي على ملفات الموقع.

🚀
الخطوة 07

نشر المشروع

بعد ربط المستودع وإعدادات النشر، نضغط على Deploy لتبدأ منصة الاستضافة بنشر الموقع وإتاحته عبر الإنترنت.

النتيجة:

الحصول على رابط إلكتروني يمكن فتحه ومشاركة الموقع من خلاله.

🌍
الخطوة 08

حجز دومين للموقع

نحجز اسم نطاق (Domain) مناسبًا يعبر عن الموقع، ثم نربطه بمنصة الاستضافة ليصبح للموقع عنوان خاص وسهل التذكر.

مثال:

www.mywebsite.com


وبذلك تكتمل رحلة إنشاء الموقع من الفكرة إلى الإطلاق.
